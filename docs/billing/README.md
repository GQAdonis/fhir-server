# Billing and prior authorization

**Owner:** `billing-prior-auth-specialist`.

Payer documentation requirement workups, prior-authorization workflow notes, and denial and appeal pattern summaries. The process is the `payer-documentation-rules` skill. **Every payer rule must cite its source** (LCD/NCD with revision date, or the payer policy URL with its number and effective date).

**Patient-data rule:** use placeholders (`[PATIENT]`, `[DOS]`, `[ID]`) and aggregate counts only. **Never** add patient data, claim numbers or member IDs. Drafting with real details is allowed only on a Tribe lane, and the output stays out of this repository (see `phi-lane-policy`).
