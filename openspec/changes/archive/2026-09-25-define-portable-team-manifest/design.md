## Context

`agent-team-creator`'s `guide` covers only generic areas (see assessment), so the manifest is authored directly, which is the skill's documented expert path. Existing `.claude/agents/fhir-*.md` bodies are the prompt source for the 9 kept roles.

## Goals / Non-Goals

**Goals:** one manifest; lossless port of existing prompts; explicit ownership; the Harness card and PHI-lane block generated consistently.

**Non-Goals:** exporting or installing into harnesses (next change); changing engineering prompt semantics beyond the two merges.

## Decisions

- **The manifest is generated by a checked-in script.** `scripts/agent-team/build-manifest.mjs` reads a small role catalog (`.agent-team/roles/*.md`, one prompt body plus a YAML-subset header per role) and emits `team.json`. Editing prose in Markdown is reviewable; the JSON is derived. Rejected alternative: hand-editing `team.json`, whose prompts would be escaped JSON strings.
- **The Harness card and PHI-lane block are rendered by the build script** from per-role fields (`phiLane: none|tribe-only|policy-only`, `models: {claude, codex, opencode, kimi, minimax}`, `tools`). This keeps the 14 cards identical in structure.
- **Model map, by tier:**
  - hard: Claude `opus`, MiniMax `MiniMax-M3`;
  - medium: Claude `sonnet`;
  - low: Claude `haiku`.
  - Codex and OpenCode entries come from `agent-team-models models-discover` output recorded in evidence. Kimi's entry is informational, since Kimi ignores per-role models.
- **Merges:**
  - the architect absorbs the ideation strategist's research and goal-drafting duties and its web and Firecrawl tools;
  - the tech lead absorbs curation (ledger health, reflection lessons) as an invoked skill, not a separate persona.

## Risks / Trade-offs

- [Prompt loss during the port] → task 2.1 diffs each ported body against the original `.claude/agents` file and records the diff in evidence.
- [The `agent-team-creator` worktree build may change] → record its path and commit in `.agent-team/team.json` `native.*.version` and in evidence.
