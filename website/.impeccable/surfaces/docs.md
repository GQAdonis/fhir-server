# Surface brief: Tribe Health FHIR Server docs (website/, all /docs routes)

Scope: the Docusaurus documentation site. Mode: Read.
Audience: platform engineers, integration teams and AI app builders reading setup, API and architecture pages, often beside a terminal, in light or dark OS mode.
Job: find the page, understand the behaviour, copy the command. Wayfinding (sidebar, TOC, search) and code legibility outrank expression.
Proof/content: the existing docs pages, unchanged in substance; product renamed to Tribe Health FHIR Server with fork-of-WSO2 attribution. The FHIR 262 page keeps describing the upstream image it actually tests.
Constraints: brand from ../../simple-ai-care/DESIGN.md (Cited Letter); light + dark (user-confirmed 2026-09-26); Nexa self-hosted (user confirmed license); WCAG 2.2 AA; synthetic data only; links point to GQAdonis/fhir-server, hosted at https://gqadonis.github.io/fhir-server/.
Decided without a roll: the Impeccable engine was unavailable (no concept-seed); the world is brand-pinned, so only the Read-mode translation was chosen by hand.

## Direction contract

THESIS: The docs are the evidence file behind the letter: each page is a white sheet laid on the desk, reference material you can cite. It refuses the stock Docusaurus look (tinted pills, rounded callout cards, a one-accent orange skin).

OWN-WORLD: Cool desk ground (#eef1f4) with the page as a square-edged white sheet carrying the single paper elevation; Ink Navy (#003b5c) owns code blocks, the footer band and active states; Highlighter yellow only for evidence in focus (the heading you jumped to, search hits, selection). Met/gap/void map to tip/warning/danger. Nexa for headings and chrome, Source Serif 4 for prose, system mono for code. Dark mode is the night desk: the same world under navy, sheet a lifted navy.

STORY: A reader lands on a page, sees the Tribe Health mark and the product name, reads comfortable serif prose on a sheet, copies commands from navy code fields, and jumps between sections without losing their place.

FIRST VIEWPORT: Desk navbar with the mark, "Tribe Health" in Nexa Heavy, a hairline, "FHIR Server"; sidebar on the desk at left; the sheet holds the page title in Nexa 800 and prose at ≤68ch; TOC on the desk at right under an uppercase Nexa label.

FORM: Cited Letter translated to Read mode; position 1 (brand-pinned); seed key: none (engine unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
